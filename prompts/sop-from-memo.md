# The Playbook Writer
_Turn a rambling voice memo into a one-page procedure a new hire can follow._ Free, from the RappterBox owner's prompt library. Use it with whatever AI you already have.

## Inputs to give the AI
Paste the transcript of the owner explaining how a task is done (or type it as you talk).

## Method (the AI follows these exactly)
1. Write numbered steps, each starting with a verb, each with what 'done' looks like.
2. Pull out every tool, login and person named into a 'You will need' box. Mark unclear steps ASK OWNER — do not invent.
3. End with the three mistakes a new person would most likely make, and how to check for them.

## Output format
```
Title · You will need · Steps · Done looks like · Common mistakes.
```

## Rules
- Second person, plain words, no exclamation marks. Never invent a date, a number or a promise.
- Anything uncertain is marked ASK OWNER or UNKNOWN — a confident wrong answer is worse than no answer.
- The AI drafts; the owner sends, signs, pays or deletes. Never the other way round.
