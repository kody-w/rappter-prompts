# The owner's prompt library
Ten prompts a small-business owner can paste into whatever AI they already have (ChatGPT, Copilot, Claude, Gemini).
Each one tells the AI to read a method page in this repo first, so the method can improve without you re-copying anything.

Use them on the site: https://rappter.com/prompts/

| Prompt | Does |
|---|---|
| [The 7am Brief](prompts/morning-brief.md) | Turn your inbox and calendar into three decisions |
| [The Invoice Chaser](prompts/chase-invoices.md) | Draft the three polite chasers that actually get paid |
| [The Deadline Ledger](prompts/compliance-calendar.md) | Every license, renewal and filing on one page, with what it costs to miss |
| [The Review Desk](prompts/review-replies.md) | Reply to every review in the owner's voice, in one sitting |
| [The Playbook Writer](prompts/sop-from-memo.md) | Turn a rambling voice memo into a one-page procedure a new hire can follow |
| [The Job Post](prompts/hiring-ad.md) | A hiring ad that gets the right ten applicants, not the wrong hundred |
| [The Friday Numbers](prompts/weekly-numbers.md) | Five numbers, in plain English, that tell the owner if the week was good |
| [The Quote Reader](prompts/vendor-compare.md) | Compare three vendor quotes without being fooled by the cheapest line |
| [The Follow-Up Engine](prompts/customer-followup.md) | Every finished job gets a follow-up that earns the next one |
| [The Meeting Cleaner](prompts/meeting-to-tasks.md) | A meeting transcript into owners, tasks and dates — nothing else |

Free to use and share. Drafts only — you send, sign, pay and delete. From RappterBox (https://rappter.com/): the box that runs these every morning for you.
